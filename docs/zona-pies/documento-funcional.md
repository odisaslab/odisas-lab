# ZONA PIES — Documento funcional para rediseño y evolución digital

> Documento de referencia del proyecto. Recoge el briefing funcional tal como lo facilitó el cliente. Las instrucciones de ejecución se darán aparte.

---

## 01. Objetivo del proyecto

Crear una nueva web para Zona Pies que posicione la empresa como un **laboratorio de fabricación de ortesis plantares tecnológico, preciso, profesional e innovador**.

La nueva web no debe limitarse a mostrar información. Debe:

- Explicar qué hace Zona Pies.
- Mostrar visualmente su tecnología.
- Transmitir precisión y confianza.
- Diferenciarla de laboratorios tradicionales.
- Captar nuevos profesionales.
- Generar solicitudes de presupuesto.
- Facilitar el contacto por WhatsApp y teléfono.
- Explicar materiales y procesos de fabricación.
- Potenciar la imagen de marca.
- Convertir la experiencia de navegación en algo memorable.

El objetivo principal es que un podólogo, clínica o profesional que entre en la web piense:

> "Esto no parece un laboratorio tradicional. Esto es una empresa tecnológica especializada en ortesis plantares."

## 04. Concepto creativo

### "DEL ESCANEO A LA PLANTILLA"

La nueva web utiliza como concepto narrativo el recorrido de un pie desde:

**ESCANEO → DISEÑO → FABRICACIÓN → RESULTADO**

El usuario debe sentir que está entrando dentro del proceso tecnológico de Zona Pies.

### Idea visual

Al entrar, un modelo 3D de un pie aparece en pantalla. El pie comienza a ser escaneado. A medida que el usuario hace scroll:

| Paso | Fase | Qué ocurre |
|------|------|-----------|
| 01 | **SCAN** | Se digitaliza el pie. |
| 02 | **DESIGN** | La geometría se transforma en un modelo digital. |
| 03 | **ENGINEERING** | Se selecciona material, dureza, estructura y características. |
| 04 | **MANUFACTURING** | La plantilla comienza a fabricarse. |
| 05 | **RESULT** | Aparece la ortesis terminada. |
| 06 | **YOUR PATIENT** | CTA para solicitar presupuesto o comenzar un pedido. |

Esto convierte el proceso de fabricación en el storytelling principal de la web.

## 05. Dirección artística

La estética debe transmitir: **TECNOLOGÍA + PRECISIÓN + SALUD + INNOVACIÓN**.

No debe parecer:

- una clínica tradicional;

- una web médica antigua;

Debe parecer una mezcla entre: **laboratorio tecnológico + ingeniería + healthcare premium**.

- Mucho espacio negativo.
- Tipografía moderna.

- Animaciones suaves.
- Microinteracciones.
- Elementos técnicos.
- Líneas y grids.
- Datos visuales.
- Transiciones cinematográficas.
- Fotografías macro de materiales.

## 07. Sección "El proceso"

Una de las partes más importantes de la web. Mostrar el proceso mediante **scroll storytelling**:

1. **ESCANEA** — Digitalización precisa de la anatomía plantar.
2. **ANALIZA** — Interpretación de la geometría y necesidades.
3. **DISEÑA** — Diseño digital de la ortesis.
4. **FABRICA** — Fabricación mediante materiales técnicos y procesos avanzados.
5. **ENTREGA** — Resultado final preparado para el profesional.

Cada etapa debe tener:

- animación;
- número;
- gráfico;
- información;
- elemento 3D;
- CTA contextual.

## 08. "¿Qué necesitas?"

Esta sección debe convertirse en un **selector interactivo** con tres opciones:

1. **QUIERO QUE FABRIQUÉIS MIS PLANTILLAS** — Para profesionales que quieren externalizar la fabricación.
2. **QUIERO SOLO EL SHELL** — Para profesionales que realizan parte del proceso.
3. **QUIERO FABRICAR MIS PROPIAS PLANTILLAS** — Presentar soluciones y sistemas disponibles.

El usuario selecciona una opción y la web **adapta dinámicamente la información**.

- mobile first;
- carga progresiva;
- lazy loading;
- imágenes WebP/AVIF;
- vídeos optimizados;
- 3D optimizado;
- animaciones GPU;
- evitar elementos innecesariamente pesados;
- accesibilidad;
- buen Core Web Vitals.

La experiencia debe ser espectacular en desktop y seguir siendo fluida en móvil.
